# KaamSetu

Android app (Flutter) connecting farmers, employers and workers.
Backend: Spring Boot + MySQL.

## Team and responsibilities

- Arushi: Backend auth, security, user, admin, common, migrations and scripts.
- Simran: Backend jobs, applications, reviews, reports and Postman.
- Purva: Mobile core, shared, localization, auth, profile and worker features.
- Gayatri: Mobile employer features and design.

## Project structure

- backend/ : Java Spring Boot backend
- mobile/ : Flutter Android application
- design/ : Wireframes and user testing
- postman/ : API testing collection
- scripts/ : Setup and maintenance scripts
- docs/ : Project documentation
